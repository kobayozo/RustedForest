# RustedForest

Three.js 製の三人称アクション RPG プロトタイプです。草原と城塞を探索し、野盗・魔女・野生動物・ドラゴンと戦います。

## すぐ遊ぶ

前提: **Node.js 18+**（推奨 20+）

```bash
git clone https://github.com/kobayozo/RustedForest.git
cd RustedForest
npm install
npm run dev
```

ブラウザで表示された URL（通常は http://127.0.0.1:5173/ ）を開いてください。  
最初のクリック／キー入力で音声が有効になります。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーでプレイ |
| `npm run build` | 本番用ビルド（`dist/`） |
| `npm run preview` | ビルド結果の確認 |

## 操作

### キーボード / マウス

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| 視点 | マウス移動（クリックでポインターロック） |
| 軽攻撃 | 左クリック |
| 重攻撃 | 右クリック |
| ロール / ダッシュ | `Space`（短押しロール・長押しダッシュ） |
| 盾構え | `Q` |
| キック | `E` |
| ロックオン | `F` |
| 聖杯瓶（回復） | `C` または `1`（HUD 表記は Y / パッド準拠） |
| かがり火で休息 | `T`（かがり火付近） |

### ゲームパッド（Xbox 系）

| 操作 | ボタン |
|---|---|
| 移動 / 視点 | 左 / 右スティック |
| 軽攻撃 | RB |
| 重攻撃 | RT |
| ロール / ダッシュ | B |
| 盾 | LB |
| キック | LT |
| ロックオン | R3 |
| 聖杯瓶 | Y |
| 休息 | A |

## ゲームの概要

- **プレイヤー**: 剣と盾の騎士。軽い3段コンボ・重攻撃・キック・ガード・回避・聖杯瓶
- **敵**: 野盗、儀式の魔女（遠距離魔法）、野生動物、城のドラゴン（ボス）
- **BGM**: 探索時は複数曲からランダム、通常戦闘 / ボス戦闘で切替

## トラブルシューティング

- **画面が黒い / 読み込みが長い**: 初回はモデル読み込みに時間がかかります。コンソールエラーを確認してください
- **音が鳴らない**: ページをクリックするかキーを押してください（ブラウザの自動再生制限）
- **ポートが使われている**: 別の Vite が起動していないか確認し、止めてから `npm run dev` し直してください
